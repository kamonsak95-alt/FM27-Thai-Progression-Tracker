# v1.0.35 — หาตัวตายตัวแทนและโปรไฟล์ที่อ่านง่ายขึ้น

- เพิ่ม **หาตัวตายตัวแทน** ในโปรไฟล์นักเตะ เลือกตำแหน่ง อายุ มูลค่า และ CA/PA ขั้นต่ำ แล้วดู 20 อันดับที่มีรูปแบบค่าพลังใกล้เคียง พร้อมเปิดโปรไฟล์หรือเปรียบเทียบกับต้นแบบ
- โหมด **พร้อมแทนตอนนี้** เริ่มที่ CA อย่างน้อย CA ต้นแบบ −20 ส่วน **ปั้นไว้แทน** เริ่มที่ PA อย่างน้อย CA ต้นแบบ −10 ไม่กำหนด CA ขั้นต่ำ ทั้งสองโหมดไม่มีเพดานบนและปรับเงื่อนไขเองได้
- ใช้ข้อมูลจากรอบสแกนล่าสุดเดียวกัน โดย CA/PA คัดคนก่อน แล้วใช้ Attributes จัดอันดับ คะแนนสไตล์ไม่ใช่คะแนนฝีเท้าหรือโอกาสพัฒนาสำเร็จ และไม่รวมสถิติแฝงในคะแนน
- เพิ่มผังตำแหน่งขนาดเล็กในโปรไฟล์ แสดงตำแหน่งที่เล่นได้เป็นสีเขียว ดูอย่างเดียวและไม่เปลี่ยนฟิลเตอร์
- พับ **ลักษณะนิสัยและสถิติแฝง** ไว้ทุกครั้งที่เปิดโปรไฟล์นักเตะหรือทีมงาน เพิ่มสีตัวเลขและพื้นหลังตามทิศทางของค่า พร้อมคำอธิบายเมื่อชี้เมาส์
- ค้นชื่อโดยไม่ต้องพิมพ์เครื่องหมาย เช่น **sesko → Šeško**, **jurgen → Jürgen** ได้ทั้งรายชื่อนักเตะ ทีมงาน และการค้นหาคู่เปรียบเทียบ โดยยังแสดงชื่อสะกดเดิม
- ปรับ **ล้างทั้งหมด** เป็นปุ่มสีแดงทั้งสองหน้า ตรึงหัวข้อและตัวกรองในหน้าหาตัวแทน และปิดโปรไฟล์ตัวแทนแล้วกลับรายชื่อเดิมพร้อมเงื่อนไขและตำแหน่งเลื่อน

ดาวน์โหลด Setup เพื่อติดตั้งหรืออัปเกรด หรือแตก Portable ZIP แล้วเปิด **bin/FM27-Tracker.exe** มี Node.js Runtime ในแพ็กเกจ ไม่ต้องติดตั้ง Node.js เพิ่ม
