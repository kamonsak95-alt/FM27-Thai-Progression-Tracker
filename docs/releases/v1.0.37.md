# v1.0.37 — คืนทีมงานว่างงานให้ค้นหาได้

- แก้ทีมงานว่างงานบางคนหายจากผลค้นหาหลัง v1.0.36 เช่น **Jonny Evans (ID 5005078)**
- รองรับตำแหน่งที่ต้องการ **โค้ชลูกตั้งเตะ** และ **นักกายภาพบำบัด** เพิ่มเติม ทีมงานว่างงานที่ยังระบุบทบาทไม่ได้ยังค้นหาได้ โดยไม่เดาว่าเป็นโค้ชหรือสร้างดาวฝึกสอนให้
- ฝ่ายบริหารสโมสรยังถูกแยกออกจากรายชื่อโค้ชและช่องค้นหาคู่เปรียบเทียบตามเดิม
- เอาการตรึงหัวคอลัมน์ตาราง **นักเตะและทีมงาน** ที่เพิ่มใน v1.0.36 ออก กลับไปเลื่อนตามหน้าแบบเดิม
- ไม่เปลี่ยน Scanner Binary และไม่ลบประวัติหรือข้อมูลสแกนของผู้ใช้

ผู้ใช้เดิมกด **เช็กอัปเดต → อัปเดตและเปิดใหม่** หรือดาวน์โหลด Setup เพื่อติดตั้งทับ สำหรับ Portable ZIP ให้แตกไฟล์ทั้งหมดแล้วเปิด **bin/FM27-Tracker.exe**
