# v1.0.38 — แก้รายชื่อโค้ชลูกตั้งเตะที่มีสังกัด

- แก้โค้ชลูกตั้งเตะที่มีสังกัดถูกแสดงเป็นนักวิเคราะห์ผลงาน ทำให้กรองตำแหน่งแล้วเจอเฉพาะคนว่างงาน เช่น Nicolas Jover ของ Arsenal และ Matt Neil ของ MK Dons
- รายชื่อ ตัวกรอง โปรไฟล์ และช่องค้นหาคู่เปรียบเทียบใช้บทบาทที่แก้ไขตรงกันแล้ว เลือกสถานะ **ทุกสถานะ / มีสังกัด / ว่างงาน** ได้ตามปกติ
- ทีมงานว่างงานยังค้นหาได้ตามเดิม นักวิเคราะห์ผลงานและฝ่ายบริหารยังแยกบทบาทตามเดิม
- ใช้ได้กับข้อมูลสแกนเดิมที่มีรหัสงาน ไม่ต้องลบประวัติหรือเริ่มบันทึกใหม่

ผู้ใช้เดิมกด **เช็กอัปเดต → อัปเดตและเปิดใหม่** หรือดาวน์โหลด Setup เพื่อติดตั้งทับ สำหรับ Portable ZIP ให้แตกไฟล์ทั้งหมดแล้วเปิด **bin/FM27-Tracker.exe**
