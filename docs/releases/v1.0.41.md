# v1.0.41 — ชุดค้นหา บทบาท และผังวิเคราะห์ทีม

- **บันทึกชุดค้นหา** เก็บช่วงอายุ CA/PA และตัวกรองนักเตะเป็นชุดตั้งชื่อ ใช้ร่วมกันได้ทุกเซฟ และกดลบได้จากเมนู ชุดค้นหาเก็บในไฟล์ `saved-searches.json` ในโฟลเดอร์ข้อมูลของ Tracker
- **ค้นหาตามบทบาท** เลือกตำแหน่งเดียวหรือหลายตำแหน่งบนผังสนาม แล้วเลือกบทบาทจากตำแหน่งที่เลือก Tracker กรองผู้เล่นตามตำแหน่งที่รองรับและเรียงตามค่าเฉลี่ยของค่าพลังที่เกี่ยวข้อง เต็ม 20 คะแนน
- **ผังสนาม 2D** ใน **วิเคราะห์ทีม → ภาพรวม** ตำแหน่งที่ควรเสริมหรือขาดผู้เล่นใช้สีส้มพร้อมเครื่องหมาย **!** ตามสถานะในการ์ดรายละเอียด
