# FM27 Scout & Tracker v1.0.47

- เพิ่มเมนู **เรียงพัฒนาการ** เหนือตารางนักเตะ เลือกเรียงตาม **แต้ม CA** หรือ **เปอร์เซ็นต์ (%)** ได้
- หัวคอลัมน์ **CA เทียบรอบแรก** และเมนู **พัฒนาการสูงสุด** ใช้เกณฑ์ที่เลือก ตารางยังแสดงทั้งแต้มและเปอร์เซ็นต์
- เมื่อกด **ล้างทั้งหมด** เมนูจะกลับเป็น **แต้ม CA** และตารางจะกลับไปเรียงตาม CA ปัจจุบันจากมากไปน้อย

อัปเดตผ่าน **เช็กอัปเดต** หรือปิด Tracker ก่อนเปิดไฟล์ Setup ที่ดาวน์โหลดเอง
