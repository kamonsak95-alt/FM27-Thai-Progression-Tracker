# FM27 Scout & Tracker v1.0.46

- **จัดการประวัติเซฟ** ดูวันที่ของรอบล่าสุด จำนวนรอบสแกน และพื้นที่ที่จะคืนโดยประมาณ แล้วเลือกลบประวัติเซฟเก่าได้ ไฟล์เซฟ FM27 และ Shortlist ยังอยู่ หากกลับมาเล่นเซฟเดิม Tracker จะเริ่มบันทึกใหม่เมื่อสแกนอีกครั้ง
- **ฟิลเตอร์ทีมงาน** เพิ่มปุ่มเลือกและบันทึกฟิลเตอร์ในหน้าทีมงาน รายการฟิลเตอร์แยกจากหน้านักเตะและใช้ซ้ำได้ทุกเซฟ
- **ทีมงานทีมเรา** เพิ่มตัวกรองทีมงานของสโมสรและภาพรวมตำแหน่งทีมงานใน **วิเคราะห์ทีม → ทีมงาน**
- **ค้นหานักเตะ** ย้ายปุ่ม **นักเตะทีมเรา** ไปถัดจาก **ทั้งหมด** และใช้ชื่อ **เลือกฟิลเตอร์** กับ **บันทึกฟิลเตอร์** ให้ตรงกันทั้งสองหน้า

อัปเดตผ่าน **เช็กอัปเดต** หรือปิด Tracker ก่อนเปิดไฟล์ Setup ที่ดาวน์โหลดเอง
