# v1.0.39 — ค้นหานักเตะด้วยค่าพลังแฝงและลีก

- ใน **Attributes** เปิดหมวด **ลักษณะนิสัยและค่าพลังแฝง** แล้วติ๊กค่าที่ต้องการกรองได้หลายข้อ เช่น การเล่นในเกมสำคัญ 15 ขึ้นไป หรือความเสี่ยงบาดเจ็บไม่เกิน 8
- ใน **ตัวกรองเพิ่มเติม → ลีก / ดิวิชัน** พิมพ์ค้นชื่อและเลือกได้สูงสุด 12 ลีก หรือใช้ **ลีกเดียวกับทีมที่คุม** เพื่อค้นนักเตะในลีกของทีมชุดใหญ่
- หากว่างงาน โหมดลีกเดียวกับทีมที่คุมจะแสดง 0 คน ปิดโหมดนี้เพื่อเลือกลีกเองได้
