# v1.0.36 — ตรึงหัวตารางและจัดรายชื่อทีมงานให้ตรงบทบาท

- ตรึงหัวคอลัมน์ในตาราง **นักเตะและทีมงาน** ไว้ใต้ส่วนหัวแอประหว่างเลื่อนหน้า ยังกดเรียงข้อมูลและเลื่อนแนวนอนได้ตามเดิม
- เอาฝ่ายบริหารสโมสรและรายการ **Staff Member ที่ยังระบุบทบาทไม่ได้** ออกจากรายชื่อและช่องค้นหาคู่เปรียบเทียบทีมงาน
- แก้การจัดบทบาทที่เคยเดาคนไม่ทราบตำแหน่งเป็นโค้ช เช่น Francisco Salgado Zenha ซึ่งข้อมูลสแกนระบุเป็นฝ่ายบริหาร
- แสดงดาวฝึกสอนเฉพาะกลุ่มฝึกสอน และกรองดาวเฉพาะกลุ่มนี้ ไม่คำนวณดาวให้ฝ่ายบริหาร แมวมอง หรือทีมแพทย์
- ไม่แก้ Scanner Binary และไม่ลบข้อมูลสแกนหรือประวัติของผู้ใช้

ผู้ใช้เดิมกด **เช็กอัปเดต → อัปเดตและเปิดใหม่** ได้จากในแอป หรือดาวน์โหลด Setup เพื่อติดตั้งทับ สำหรับ Portable ZIP ให้แตกไฟล์ทั้งหมดแล้วเปิด **bin/FM27-Tracker.exe** มี Node.js Runtime พร้อมใช้งานในแพ็กเกจ
