# v1.0.43 — Hotfix ประวัติเซฟตอนว่างงาน

- รองรับการเริ่มบันทึกพัฒนาการจากเซฟที่เริ่มว่างงาน เมื่อได้ทีมคุมแล้วใช้รหัสเซฟและประวัติเดิมต่อ
- เมื่อกลับมาว่างงานและตัวสแกนอ่านวันที่ไม่ได้ Tracker แสดงวันที่ยืนยันล่าสุดของเซฟที่ระบุได้ และรอให้ระบุวันที่จริงก่อนบันทึกรอบใหม่
- เมื่อระบุกุนซือไม่ได้ สามารถยืนยันด้วยชื่อเต็มหรือ ID จากในเกม คำยืนยันจะผูกกับผลสแกนรอบนั้นและยังใช้ได้เมื่อเปิด Tracker ใหม่
